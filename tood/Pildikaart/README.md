# ÜL2: Pildikaart

Pealeht: Pildikaart.html. Kuus koopiat: notobuk.html, lamp.html, lill.html, laud.html, tool.html ja tumba.html.

- Kõigil lehtedel kasutatakse sama kohalikku pilti tumba.png (1024 × 1024).
- Kuus ala kasutavad rect-, circle- ja poly-kujundeid. Koordinaadid põhinevad originaalpildi mõõtmetel.
- pildikaart.js skaleerib koordinaadid pildi laiuse järgi ja kuvab kirjelduse samal lehel.
- Ilma JavaScriptita on kirjeldused tekstina loetavad ning lingid viivad sama lehe ankruteni.
- Kujundus on failis styles.css. Vana Style.css jääb alles teiste varasemate lehtede jaoks.
- Kodulehe link kasutab selle kausta asukohale vastavat suhtelist teed.

## Kontroll
Seitse HTML-lehte kontrolliti Nu HTML Checkeriga (https://validator.w3.org/nu/): vigu ega hoiatusi ei olnud.
Brauseris kontrolliti kõiki kuut ala igal lehel laiustel 1280 ja 390 pikslit (84 klõpsu), algset valikut koopiatel ning klaviatuuriga aktiveerimist.

## Pildi päritolu
Foto tumba.png oli olemas algses repositooriumis ja on siin säilitatud.
Algallikat ega jagamislitsentsi repositooriumis ei olnud. Enne töö esitamist tuleb lisada foto allikas ja jagamist lubav litsents või asendada foto lubatud pildiga ning kohandada koordinaadid.
